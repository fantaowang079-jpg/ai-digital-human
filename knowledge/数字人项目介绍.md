# AI 数字人对话系统 · 项目介绍

## 项目简介

这是一个从零实现的精简 AI 数字人对话系统，完整覆盖「听 → 想 → 说 → 动」四个环节：
麦克风语音输入、大模型思考、语音合成播报、数字人口型动画。系统采用可插拔 Provider
架构，不依赖高端 GPU，普通笔记本电脑即可运行。

## 核心功能

1. 文字对话：页面输入文字，数字人用语音回复。
2. 语音输入：点击麦克风说话，使用 Faster-Whisper 在本地完成语音识别。
3. 流式回复：大模型边生成、边分句、边合成语音，前端逐句播放，首句延迟约 4 秒。
4. 连续对话：VAD 检测到停顿 2 秒后自动识别，回复播完自动重新聆听。
5. 口型动画：用 Web Audio 分析播放音量，实时驱动 SVG 数字人的嘴巴开合。
6. 知识库问答：上传专有领域文档后，数字人优先依据知识库回答。

## 技术架构

- 前端：原生 HTML、CSS、JavaScript，SVG 数字人形象，Web Audio API 做音频播放和音量分析。
- 后端：Python FastAPI，提供 `/api/chat`、`/api/chat/stream`、`/api/stt` 等接口。
- 编排层：pipeline.py 负责注入角色设定与知识库上下文、流式分句、串联各 Provider。
- 可插拔 Provider：LLM 支持 Mock 和 DeepSeek；TTS 使用 Edge-TTS；STT 使用 Faster-Whisper。
- 通信协议：流式接口使用 NDJSON，每行一个 JSON 事件，类型为 sentence 或 error。

## 知识库（RAG-lite）设计

- 支持 txt、md、csv、pdf、docx 文档，上传后保存到 knowledge 目录并自动重建索引。
- 中文检索使用单字与相邻二元组切词，计算 TF-IDF 余弦相似度，无需向量数据库和 GPU。
- 每次提问检索最相关的若干片段，拼接到 system prompt，要求模型优先依据资料回答。
- 没有命中资料时保持普通闲聊能力；开启 KB_STRICT 后要求模型明确说明知识库中没有相关信息。
- 相关度阈值由 KB_MIN_SCORE 控制，默认 0.05；注入片段数由 KB_TOP_K 控制，默认 4。

## 技术栈与环境

- Python 3.12，虚拟环境位于项目的 .venv 目录。
- 依赖：fastapi、uvicorn、edge-tts、faster-whisper、requests、python-dotenv、pydantic、python-multipart、pypdf。
- 大模型使用 DeepSeek 的 deepseek-flash，已关闭思考模式以降低延迟。
- 显卡为 GTX 1650 4GB，无法运行实时口型模型，因此口型采用轻量的音频振幅驱动方案。
- 首次语音识别会从 hf-mirror 下载 Whisper base 模型，约 150MB。

## 启动方式

在 Windows 上双击项目根目录的「启动数字人.bat」，或者执行：
cd E:\digital-human
.venv\Scripts\python.exe -m uvicorn backend.main:app --port 8000

然后浏览器访问 http://localhost:8000 。

## 性能与限制

- 流式回复首句延迟约 4 秒，主要耗时在首句大模型生成与语音合成。
- 当前使用 Whisper base 模型，识别准确率一般，可以换 small 模型或云端 ASR 提升。
- 系统是本地演示项目，没有登录鉴权，不要直接暴露到公网。
- 知识库为轻量词法检索，适合几十篇文档的小型知识库；大规模语料可换成向量检索。

## 常见问题

问：知识库支持哪些文件格式？
答：支持 txt、md、markdown、csv、pdf、docx，单个文件最大 10MB。

问：上传知识库后需要重启吗？
答：不需要。上传成功后会立即重建索引，下一次提问就会生效。

问：为什么数字人有时回答「知识库中没有找到相关信息」？
答：说明问题与知识库内容的相似度低于阈值，或者知识库确实没有覆盖该内容。
可以调整 KB_MIN_SCORE，或补充更完整的文档。

问：如何让数字人只回答知识库里的内容？
答：在 .env 中设置 KB_STRICT=true，模型在没检索到资料时会被要求明确说明不知道。

问：这个项目用到向量数据库吗？
答：没有。知识库检索使用 TF-IDF 余弦相似度，纯 Python 实现，零额外服务依赖。
