使用说明

  1. 开始对话

    在下方输入框打字，或点 🎤 用语音说话。

  2. 允许麦克风

    第一次点 🎤 时浏览器会询问权限，请点「允许」。请使用 http://localhost:端口 访问，局域网 IP 下浏览器会禁用麦克风。

  3. 说完停顿即可发送

    对话框下方「音量」条显示麦克风音量；「判定」条在你停止说话后开始缩短， 走完会自动识别并发送。右下角「停顿」可调 1–4 秒。

  4. 随时打断

    数字人说话时面板会显示「监听中」，此时直接开口即可打断； 也可以点 ⏹ 停止播报。

  5. 接入真实大模型（可选）

    默认是 Mock 模式（占位回复）。点右上角「🔑 API Key」按钮， 粘贴自己的 DeepSeek Key 并保存，立即生效，不需要改 .env，也不需要重启。

  6. 上传资料（可选）

    点输入框左侧的 📚 按钮打开知识库，上传 txt / md / csv / pdf / docx。 开启「对话时使用知识库」后，回答会优先依据资料， 并在气泡下方标出参考文件。

  7. 常见问题

    首次语音识别需要加载模型，等几秒属正常；外放音箱若出现自己打断自己， 建议戴耳机或把 .env 的 BARGE_IN_THRESHOLD 调高到 0.04–0.05；更多排查见文件夹里的「使用说明.txt」。
