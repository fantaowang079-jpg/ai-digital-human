使用指南 · 提示助手

      

        
🚀 快速开始

        
    
          
  1. 把整个便携包 完整解压 到桌面或文档目录，不要直接在 zip 预览里双击。
    2. 
          
  2. 双击 start.bat（或 启动数字人.bat）。
    3. 
          
  3. 浏览器自动打开；如果没打开，按黑窗口显示的地址访问（通常是 http://localhost:8000）。
    4. 
          
  4. 首次使用按提示粘贴自己的 DeepSeek API Key；没有 Key 点「先体验」即可，语音功能仍然可用（只是回复为 Mock 内容）。
    5. 
          
  5. 关闭黑色服务器窗口即停止服务。
    6. 
        


        
🎭 两种模式

        

          专业模式 · 知语：只依据知识库回答，标注引用来源，资料不足会说「知识库中没有找到相关信息」。

          心理医生模式 · 心语：不查知识库，专注共情和倾听，适合闲聊。切换模式会加载该模式自己的历史记忆。
        


        
📚 知识库

        

          展开「📚 知识库」面板，上传 txt / md / csv / pdf / docx；也可以把整个文件夹放进
          knowledge/ 目录。上传后会自动重建索引，下一次提问立即生效。
          首次解析大量 PDF 可能需要几十秒，解析结果会缓存，之后重启很快。
        


        
🎤 语音输入

        

          点 🎤 开始说话，停顿约 2 秒会自动发送；也可以再点 ⏹ 立即停止并发送。
          说话时头像下方会出现麦克风电平条：条不动说明浏览器没收到声音
          （检查麦克风权限/输入设备）；条在动但没识别，请查看 logs\app.log。
          首次使用会下载语音识别模型（约 150MB），需要联网；请在浏览器允许麦克风权限。
          如果页面顶部出现「配置 API Key」提示条，点「先体验」即可，不影响语音。
        


        
📄 PDF 转文字 & 🧠 上下文记忆

        

          PDF 面板可提取文字、复制或下载 txt；扫描版 PDF 暂不支持 OCR。
          「🧠 上下文记忆」面板可以查看摘要和最近对话，刷新/重启后仍能接着聊；也可以一键清除当前模式的记忆。
        


        
❓ 常见问题

        

          提示「系统找不到指定的路径」
          

            90% 是因为没有完整解压，或在压缩包预览里直接双击。请解压整个 zip 后运行
            start.bat；确认 python\python.exe、backend\main.py
            存在。如果杀毒软件隔离了文件，请恢复或加入白名单后重新解压。
            仍然失败就双击 diagnose.bat，把生成的 logs 文件夹发回。
          

        

        

          页面显示「后端未连接」
          

            看黑色服务器窗口是否还在运行；端口是否被占用（启动器会自动尝试 8000~8010，
            以窗口显示的端口为准）；查看 logs\app.log。
          

        

        

          第一次说话没反应 / 识别很慢
          

            首次使用需要联网下载语音识别模型（约 150MB），请耐心等待并保持网络连接。
            浏览器需要允许麦克风权限。
          

        

        

          API Key 填写后仍失败
          

            Key 需要以 sk- 开头，账户有余额；可以点「配置 API Key」覆盖旧值。
            Key 只保存在本机 .env，不会上传。
          

        

        

          端口被占用
          

            启动器会自动选择 8000~8010 中空闲的端口，以黑窗口显示的
            Browser: http://localhost:端口 为准。
          

        


        
🐞 反馈问题

        

          遇到无法解决的问题，双击 diagnose.bat，把整个 logs 文件夹
          （包含 diagnose.txt 和 app.log）发给开发者。
          请不要发送 .env，里面有你的 API Key。
