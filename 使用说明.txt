AI 数字人 · 使用说明（测试版）
================================

一、运行环境
- Windows 10 / 11 64 位
- Chrome 或 Edge（推荐 Chrome）
- 需要联网：语音合成、真实大模型调用需要网络
- 语音识别模型已内置在包内，不需要单独下载
- 无需安装 Python，运行时和依赖都在文件夹里

二、第一次启动（4 步）
1. 把整个压缩包完整解压到任意目录
   （不要在压缩包预览窗口里直接双击）
2. 双击 start.bat（或 启动数字人.bat）
3. 等黑色服务器窗口出现，浏览器会自动打开；
   如果没自动打开，按窗口里显示的 http://localhost:端口 手动访问
4. 页面首次打开会自动弹出「使用说明」，点“开始使用”即可

三、怎么对话
1. 打字：在下方输入框输入内容，按回车或点“发送”
2. 语音：点 🎤，浏览器询问麦克风权限时点“允许”；
   说完话停顿一下，「判定」条走完会自动识别并发送
3. 调停顿：面板右下角“停顿”滑块可调 1–4 秒（默认 2 秒）
4. 打断：数字人说话时，你直接开口即可打断；也可以点 ⏹ 停止播报
5. 再看说明：数字人卡片右上角的“使用说明”按钮

四、接入真实大模型（可选）
- 默认是 Mock 模式，回复是占位文字，用于测试语音全链路
- 关闭黑色服务器窗口，用记事本打开 .env（首次启动会自动生成）
- 修改这两行：
      LLM_PROVIDER=deepseek
      DEEPSEEK_API_KEY=你自己的 Key
- 保存后重新双击 start.bat
- 注意：.env 里是你的私人 Key，不要发给别人

五、语音识别模型
- 本测试包已内置 faster-whisper base 模型：
      models\faster-whisper-base\
- 第一次点 🎤 时需要加载模型，等待几秒属于正常
- 如果删除了 models 目录，程序会自动从 hf-mirror 下载约 150MB 模型
  （需要联网，下载一次后复用缓存）

六、常见问题
- 双击一闪而过 / 提示缺少文件：
  多半没有完整解压，或杀毒软件隔离了 python\python.exe。
  请恢复文件，并把本文件夹加入杀毒软件白名单
- Windows 提示“未知发布者”：点“更多信息” → “仍要运行”
- 浏览器没自动打开：看黑窗口里的端口号，手动访问 http://localhost:端口
- 打开页面但麦克风没反应：
  请务必用 http://localhost:端口 访问，不要用局域网 IP；
  再检查地址栏左侧的站点设置，把麦克风改为“允许”并刷新
- 没有声音：检查系统默认输出设备；语音合成需要联网
- 数字人自己打断自己：外放音箱时可能出现，建议戴耳机；
  或把 .env 里的 BARGE_IN_THRESHOLD 调到 0.04–0.05
- 需要排查：运行 diagnose.bat，把 logs\diagnose.txt 发回给测试负责人

七、目录说明
- start.bat / 启动数字人.bat   启动入口
- run_server.bat               服务器启动脚本
- diagnose.bat                 生成诊断报告
- backend\                     后端代码
- frontend\                    网页界面
- python\                      内置 Python 运行时与依赖
- models\                      内置语音识别模型
- .env.example                 配置模板
- logs\                        运行日志（可删除）
- README.md                    开发者文档
